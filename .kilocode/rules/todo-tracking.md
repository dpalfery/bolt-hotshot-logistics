# todo-tracking.md

when creating a todo list or a status tracking markdown file always create them in the 6-docs/status folder

## Guidelines

- if you create a todo or status markdown file create it in status
- any file you need to create to maintain state or memory during a task should be created in the 6-docs/status folder
- if you task is complete you should ask the user if they want you to delete the file or files you created before completing your task. 
- if you task was assigned by the orchestrator or other agent then you should ask the agent.
