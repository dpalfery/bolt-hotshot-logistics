# Admin dashboard

Next.js App Router UI for dispatchers: jobs, drivers, tracking, billing, and Azure AD sign-in.

**Boundary:** browser client of the API. No direct SQL. Not a Vercel app in this repository.

**Entry point:** `src/app/`. Dev server: `npm run dev` (HTTPS).
